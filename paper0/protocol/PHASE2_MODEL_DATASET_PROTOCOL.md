## 1. Purpose

The exact-state and pragmatic-state experiments must differ in state and
history, not in source files, frame coverage, toroidal preprocessing, storage
precision, or normalization. This protocol freezes one shared 85604 model
dataset before the matched codec and one-step model protocol is written.

The dataset is an engineering representation of already audited simulator
outputs. Building it is not a forecast experiment, does not select a model,
and does not reopen the failed stationarity screen.

metadata but must not rewrite field arrays in normalized form.

\[
\Delta t
=
\frac{\Delta\tau}{\Omega_{ci}}
=
3.131905426352636\ {\rm \mu s}.
\]

Both the normalized coordinate and this conversion are recorded. The
converter does not relabel normalized time as seconds or microseconds.

## 4. Frozen toroidal transform

The simulation has `zperiod=5`, so the stored wedge length is

\[
L_z = \frac{2\pi}{5},
\qquad
n = 5k .
\]

Each volume field is independently transformed with exactly:

~~~python
scipy.signal.resample(
    source_float32,
    88,
    axis=-1,
    window=None,
    domain="time",
).astype(numpy.float32)
~~~

No filter, taper, smoothing, coordinate interpolation, phase shift, clipping,
or gauge subtraction is part of conversion. Native nonnegative bins
\(k=0,\ldots,40\), corresponding to full-torus
\(n=0,\ldots,200\) in multiples of five, are retained. The new 88-cell bins
\(k=41,\ldots,44\) are padding bandwidth and are not new simulator
resolution.

The inverse integrity check applies the same public transform from 88 to 81
and casts to float32.

## 5. Learning split and normalization

The converter stores all 624 development frames, but normalization is fit only
on the frozen Paper 0 training region `[0,432)`. The guard
`[432,496)` and validation region `[496,624)` contribute no statistic.

Statistics are accumulated with mergeable float64 count, mean, and
second-central-moment \(M_2\) records. The final population standard deviation
is

\[
\sigma = \sqrt{\frac{M_2}{N}} .
\]

The eight volume-field counts must each be

\[
432\times64\times32\times88 = 77{,}856{,}768.
\]

For each radial side, the \(B_\phi\) count must be

\[
432\times32 = 13{,}824.
\]

Transforms precede moment accumulation:

| Field | Transform | Statistics |
|---|---|---|
| \(N_e\) | \(\log(N_e+10^{-6})\) | one scalar mean/std |
| all other volume fields | identity | one scalar mean/std per field |
| \(B_\phi\) | identity | one mean/std per radial side |

The density transform requires every argument \(N_e+10^{-6}\) to be strictly
positive. Direct negative \(P_i\) values are retained. No field is clipped,
floored, gauge-shifted, or replaced by a derived temperature.

The authoritative statistics artifact records count, mean, \(M_2\), variance,
standard deviation, transform, fit-frame interval, and accumulator dtype.

## 6. Prospective integrity gates

No codec or dynamics job may consume the dataset until a separate validator
passes every gate below.

1. Both Well source hashes and the extraction-record hash match before any
   output is written.
2. The extraction record's eight canonical-file hashes and
   `saved_midpoint` array hashes match.
3. Input and output coverage is exactly global frames `0..623`, once each,
   with strictly increasing saved normalized time, exact normalized step
   \(300\), and the frozen physical cadence after the \(\Omega_{ci}\)
   conversion.
4. Every required input and reopened output value is finite.
5. Reopened HDF5 arrays are bitwise identical to the arrays supplied to the
   writer; array and file SHA-256 digests are recorded.
6. Resampled \(N_e\), \(\phi\), and \(V_i\) are bitwise identical on all 624
   frames to the hash-locked historical z88 files. These fields are shared
   with the legacy C5T conversion and therefore provide an end-to-end
   transform oracle.
7. For every one of the eight volume fields, the maximum per-frame
   81-to-88-to-81 relative \(L_2\) error is at most \(2\times10^{-6}\).
8. Every \(B_\phi\) output is bitwise identical to an explicit float32 cast of
   its canonical float64 source.
9. An independent, single-pass recomputation over output training frames
   reproduces each stored count exactly and each stored mean, \(M_2\),
   variance, and standard deviation to relative tolerance \(10^{-12}\) and
   absolute tolerance \(10^{-12}\). Every resulting standard deviation must
   also be finite and strictly positive.
10. The executing checkout is clean, matches the committed protocol/manifest
    hashes, runs on Rocky 9, and records versions, commands, Slurm identity,
    runtime, peak memory, and output sizes.

For a per-frame native truth \(x\) and round trip \(\widehat{x}\), use

\[
\epsilon_{\mathrm{rel}\,2}
=
\sqrt{
\frac{\sum_i(\widehat{x}_i-x_i)^2}
     {\sum_i x_i^2}
}.
\]

A zero-denominator frame passes only if the numerator is also exactly zero.
Any failed gate blocks training; it is not converted into a warning or
silently repaired.

## 7. Provenance and failure policy

Each shard is first written to a unique temporary path, reopened and
validated, and then atomically renamed. Existing final outputs are never
overwritten. A verify-only invocation may reuse them only when their recorded
manifest, protocol, commit, and content hashes all match. A mismatched existing
artifact is a hard stop.

The reducer accepts only successful partial records, proves exact disjoint
coverage, recomputes normalization, and writes one immutable dataset manifest.
Partial records contain facts, not scientific conclusions.

The tracked result will contain compact metadata, hashes, gates, compute
accounting, and a readable interpretation. Large HDF5 arrays remain on Ceph.
This protocol changes no historical checkpoint or result and authorizes no
held-out access, training, architecture selection, assimilation, or diagnostic
ranking.

## 8. What passing this gate means

A pass means that all later state arms can be assembled from one verified
source:

- `E6B-H1`: \(N_e,P_e,P_i,NV_e,NV_i,\mathrm{Vort}\) plus \(B_\phi\);
- `C5P-H2`: two ordered frames of \(N_e,P_e,P_i,\phi,V_i\);
- `C5P-H1`: one frame of the same five fields.

It does **not** mean any state is predictively sufficient, any codec preserves
transport, or any forecast is accurate. Those are the next frozen O1/O2
experiments.
